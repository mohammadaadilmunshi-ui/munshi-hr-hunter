## What changed and what is proven

- Paid compatibility entry point rejects before credential lookup, HTTP client use or paid SDK import. Stale provider_order is removed. Deterministic tests supply paid keys and assert zero network calls/imports. Existing free USAJobs key-required policy is explicitly preserved; unknown cost modes fail closed.
- Scheduler/readiness checks validate the actual shipped module, retirement/cost policy and configured boards for provider-board workers. Missing code becomes setup-required in the runtime view and cannot be newly enabled. Historical health, run metrics and source records are preserved. Replaying all 23 failed sources excludes the 22 unavailable adapters and leaves Ashby for diagnosis; this is fixture replay, not production improvement.
- New Teamtailor RSS uses only the reviewed tenant contract; no board or schedule is seeded/enabled. Real no-store canary: 2 requests (robots + feed), 2 raw, 2 normalized, 0 eligible, 0 database duplicates, 0 would-insert, 0 new/stored. Both posts are rejected by current role rules. Examples: [UK Account Executive – SMB](https://career.teamtailor.com/jobs/8118064-uk-account-executive-smb), [Revenue Systems Engineer](https://career.teamtailor.com/jobs/8546033-revenue-systems-engineer). No application page was fetched.
- Canonical fixture ingestion for Teamtailor: 6 raw/normalized; 1 eligible, 1 within-run duplicate, 2 location rejects, 1 hard-requirement reject, 1 role reject; first persistence inserts 1, repeat persistence inserts 0, protected already_applied status remains. This proves fixture integration, not a real matching production ingestion.
- Generic JSON-LD checks employer identity, exact configured host/path, posting identity, expiration, physical/remote eligibility locations and malformed payloads. Unreviewed employer URLs cannot approve themselves. No generic tenant contract has been promoted beyond the concrete RSS example; other platforms remain unverified.
- Public GET transport reuses pinned-IP HTTPS with hostname TLS validation, rejects any private/mixed DNS result, checks robots, caps time/requests/bytes, prohibits redirects and stops hosts on 401/403/429/CAPTCHA. The Ashby canary made only its robots request, received 401, stopped, and did not attempt the feed. This boundary is intentionally stricter than the unchanged existing Ashby HTTP collector.
- Existing Ashby normalization no longer assumes US for missing country. Explicit secondary locations use the same canonical gate. The latest scheduled failure is not declared fixed: old stderr is absent from retained/current container logs, and provider metrics were not recorded for that attempt.
- Recruitee counts attempted requests before HTTP failure, validates tenant locators and employer posting links, stops provider on access/rate-limit blocks, and carries Retry-After into scheduler backoff. Comeet preserves notes when quarantining invalid public boards; no-store prevents quarantine writes. Source failure remains isolated; None/NoneType JobSpy failures now propagate instead of becoming healthy empty results. The pinned JobSpy runner and version are unchanged.
